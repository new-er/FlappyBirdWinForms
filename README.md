# FlappyBird

Flappy Bird for old Windows Versions.

Written with Visual Studio 2008 targeting Windows XP. It uses Windows Forms for rendering the Game and the .NET Framework 3.5.

## Running

1. Open `FlappyBird.sln` in Visual Studio 2008 (or later).
2. Press F5 to build and run.
